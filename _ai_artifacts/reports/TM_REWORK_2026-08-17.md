Replaces 18 dead or duplicated TMs, adds 3 new ones, and rebuilds TM learnsets
across all 480 base stat files using official-game compatibility.

## Duplicates resolved

Four TMs previously appeared in two places each. Every location now gives something distinct:

- Snore ×2 → Work Up (Route 39) + Night Slash (Dark Cave)
- Steel Wing ×2 → Steel Wing (Route 28 house) + Power Gem (Rock Tunnel)
- Psychic ×2 → Psychic (Game Corner prize) + Zen Headbutt (Mr. Psychic)
- Dragonbreath ×2 → Dragon Claw (Blackthorn Gym) + Dragon Pulse (Dragon's Den)

## Learnsets

Rebuilt across 470 base stat files. Rule applied: a species gets a move only if it
legitimately learns it in the official games by any route (TM, tutor, level-up, egg,
reminder). Species counts for the changed moves:

```
Drain Punch  118    Work Up      127    Knock Off    148
Rock Tomb     97    Icicle Crash  15    Bulk Up       48
Dragon Pulse  72    Energy Ball   78    Nasty Plot    78
Will-O-Wisp   74    Facade       427    Dragon Dance  42
Iron Head    150    Dragon Claw   39    Bug Bite      48
Swagger      470    Flash Cannon  50    Hone Claws    87
Night Slash   53    Zen Headbutt 136    Power Gem     34
```

Seven swaps kept their existing distribution because the old and new moves overlap almost
entirely in the official games: Drain Punch, Rock Tomb, Energy Ball, Facade, Iron Head,
Bug Bite, Swagger.

### Custom species needing a manual pass

These aren't in the official games, so they were skipped by the canonical rule and kept only
their inherited TMs. Worth a look if any should get the new moves:

`gorotora`, `kotora`, `raitora`, `watu`, `mesmeria`

These were aliased to their official counterparts and are fine: `charmeleon_clone`,
`teddiursabm`, `ursaringbm`, `ursalunabm`, `drunsparce`.

## Engine impact

- **TM count 50 → 53.** Item IDs now run `$c2`–`$fd`. One free ID (`$fe`) remains;
  `$ff` is reserved as `ITEM_FROM_MEM` and the list terminator.
- **The `tmhm` macro did not need changing.** Its third group covers TM49+ plus HMs and
  tutors in a 16-bit field, now 15/16 used. Learnsets stay 8 bytes per species.
- **`wTMsHMs` grows from 57 to 60 bytes**, shifting WRAM after it. **Existing save files
  will not survive this** — start a new game or expect corrupted bag/TM data.
- Item space after this change is effectively full. Anything further (new berries, held
  items, key items, more TMs) needs a 16-bit item ID expansion or a separate TM pocket.

## Verification

Static validation passed:

- TM/HM/tutor totals within the 64-slot learnset array (63 used)
- item IDs within range, no overflow past `$fe`
- `tmhm_moves.asm` order matches `item_constants.asm` exactly
- every TM/HM/tutor move exists in `move_constants.asm`
- every learnset token in all 480 base stat files resolves to a real slot
- every `TM_`/`HM_` reference across `maps/`, `data/` and `engine/` resolves
- every `EVENT_` reference in `maps/` resolves after the flag renames

## Dialogue

**Move names** — 11 NPC and gym leader lines renamed: Route 31, Bugsy, Chuck, Jasmine,
Pryce, Clair (Blackthorn), Clair (Dragon's Den), Erika, Moomoo Farm, Mr. Psychic,
Viridian fisher. Goldenrod Dept 5F and the Game Corner prize clerk needed no edit — they
build their lines with `getitemname` and read the name out of the item table.

**Mechanic descriptions** — the flavour text after each gift was still describing the *old*
move. Seven were rewritten:

| NPC | Was describing | Now describes |
|-----|----------------|---------------|
| Bugsy | Fury Cutter's ramping damage | Bug Bite eating the foe's Berry |
| Chuck | DynamicPunch's accuracy and confusion | Drain Punch never missing, healing |
| Pryce | Icy Wind's speed drop | Icicle Crash's power and flinch |
| Route 31 man | Nightmare draining a sleeping foe | Hone Claws raising Attack and accuracy |
| Moomoo Farm | Snore only working while asleep | Work Up raising Attack and Sp. Atk |
| Mr. Psychic | Psychic's Sp. Def drop | Zen Headbutt's flinch chance |
| Clair (×2) | "nothing to do with my breath" — a Dragonbreath joke | Dragon Claw / Dragon Pulse flavour |

The Viridian fisher's lead-in was rebuilt around Nasty Plot — he now dreams of someone
whispering and "cooking up some nasty little scheme" instead of a Drowzee eating his dream.

**Bug fixed:** the Dragon's Den receipt text hardcoded "received TM24". Dragon Pulse is TM09,
so it displayed the wrong number. Now reads TM09.

All rewritten lines verified within the 18-character text box.

## Symbol renames

- **18 event flags** renamed (e.g. `EVENT_GOT_TM50_NIGHTMARE` → `EVENT_GOT_TM50_HONE_CLAWS`).
  Flags are saved by index, not name, so this is cosmetic.
- **33 script and text labels** renamed across 17 files, 67 references — e.g.
  `BugsyText_FuryCutterSpeech` → `BugsyText_BugBiteSpeech`, `LakeOfRageTMDetect` →
  `LakeOfRageTMDragonDance`, `ViridianCityDreamEaterFisher` → `ViridianCityNastyPlotFisher`.
  Checked for name collisions first; no stale references remain.
- `Route28SteelWingHouse` was deliberately left alone — that map still gives Steel Wing,
  and its name is wired into the map data tables.

## Still open

- **Hail** is implemented but has no TM. Celadon Mart 3F sells the other three weathers,
  so its absence is conspicuous. One free item ID (`$fe`) is left if you want it.
- **Move tutors cost no item ID** — only a learnset bit. With one bit free in the current
  array and a 9th byte costing ~500 bytes of ROM total, tutors are much the cheaper way to
  add more teachable moves from here.
