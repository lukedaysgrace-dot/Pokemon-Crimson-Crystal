# Every attack animation — Crimson Crystal

[Watch the video](Crimson-Crystal-Every-Attack.mp4). 421 moves in game index order, with embedded chapters, 1280 × 720 video at the Game Boy's native 59.7275 fps, and game audio.

[Timestamp index](timestamps.txt) · [CSV index](timestamps.csv) · [Capture manifest](manifest.json)

Captured from the current source in a private debug ROM. A capture-only debug command invokes the existing PlayBattleAnim engine in a real Mew-versus-Lugia battle scene. The animations, sprites, effects, and sound come from the game. Captures show the player side; moves that require charging or use special parameters include their listed stages or variants. This is an animation gallery, so move damage, legality, misses, and conditional battle success are not being demonstrated. Some moves intentionally share animations. Game source, release ROM, and the player's saves were preserved.

Complete video decoding, native script invocation coverage, audible capture, and all 421 embedded chapters were verified. See manifest.json for per-move phase parameters and ROM/video hashes.
