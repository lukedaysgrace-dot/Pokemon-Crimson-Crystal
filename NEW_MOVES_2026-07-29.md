# New Moves Batch — 2026-07-29

26 new moves added (move IDs 352–377, in this order):
OVERHEAT, LEAF_STORM, FAKE_OUT, FLIP_TURN, IRON_DEFENSE, ROCK_POLISH,
WOOD_HAMMER, HEAD_SMASH, DRILL_RUN, PSYCHO_CUT, SACRED_SWORD, BRICK_BREAK,
HEAT_WAVE, SNARL, NUZZLE, BULLET_SEED, DUALWINGBEAT, ROCK_TOMB, LOW_SWEEP,
MUD_SHOT, AIR_CUTTER, CROSS_POISON, MAGICAL_LEAF, SIGNAL_BEAM, SCALE_SHOT,
PHANTOMFORCE.

Everything builds clean (`make` → pokecrystal.gbc) and the ROM boots.
**Nothing learns these moves yet** — distribution (level-up learnsets, egg
moves, TMs/tutors) is intentionally left for a separate pass, per the
handoff doc's step 6.

## Mechanics implemented to match the modern games

- **Overheat / Leaf Storm** — reuse `EFFECT_DRACO_METEOR` (SpA -2 on the user).
- **Fake Out** — now a real 40 BP +3 priority move. Rebuilt its effect script
  (was the unused vanilla stub): uses `firstimpressioncheck`, so it only works
  on the user's first action opportunity after entering battle, and flinches
  (100%). Priority added to `MoveEffectPriorities` (`BASE_PRIORITY + 3`,
  above First Impression, below Protect).
- **Flip Turn** — reuses `EFFECT_U_TURN` (pivots out after attacking).
- **Iron Defense / Rock Polish** — `EFFECT_DEFENSE_UP_2` / `EFFECT_SPEED_UP_2`.
- **Wood Hammer / Head Smash** — `EFFECT_RECOIL_HIT` (Reckless/Rock Head
  interact through the existing recoil handling).
- **Drill Run / Psycho Cut / Air Cutter / Cross Poison** — added to
  `CriticalHitMoves` (high crit ratio).
- **Sacred Sword** — new `EFFECT_SACRED_SWORD`: ignores the target's DEFENSE
  stat stages in damage calc (both player and enemy sides) and the target's
  evasion stages in the accuracy check. User's own Attack boosts still apply.
- **Brick Break** — new `EFFECT_BRICK_BREAK` + new `brickbreak` battle command
  (body in the Battle Effect Overflow bank): shatters the target side's
  Reflect AND Light Screen before damage is calculated ("The wall
  shattered!"), unless the target is immune to the move (e.g. Ghost).
- **Heat Wave** — `EFFECT_BURN_HIT` 10%. Added to WindMoves (Wind Rider).
- **Snarl** — `EFFECT_SP_ATK_DOWN_HIT` 100%. Added to SoundMoves (Soundproof).
- **Nuzzle** — `EFFECT_PARALYZE_HIT` 100%.
- **Bullet Seed** — `EFFECT_MULTI_HIT` (Skill Link / Loaded Dice already
  handled by the loop core). Added to BallBombMoves (Bulletproof).
- **Dual Wingbeat** — `EFFECT_DOUBLE_HIT`.
- **Rock Tomb / Low Sweep / Mud Shot** — `EFFECT_SPEED_DOWN_HIT` 100%.
- **Magical Leaf** — `EFFECT_ALWAYS_HIT`.
- **Signal Beam** — `EFFECT_CONFUSE_HIT` 10%.
- **Scale Shot** — new `EFFECT_SCALE_SHOT`: 2–5 hits (Skill Link = 5,
  Loaded Dice = 4–5 via the shared multi-hit roll), then DEF -1 / SPE +1 on
  the user after the last hit. The self Def-drop bypasses Mist/ability
  protection (added to `CheckSelfInflictedStatDrop`, same as Draco Meteor).
  If the final hit KOs, the stat changes still happen
  (`BattleScaleShotKO_Core`, hooked from `BattleCommand_CheckFaint`).
- **Phantom Force** — reuses `EFFECT_FLY` (charge move). On the charge turn it
  prints "vanished suddenly!" and sets BOTH the flying and underground
  substatus bits — `CheckHit` treats that combination as fully unreachable
  (nothing hits it, unlike Fly/Dig). On the strike turn it goes through
  Protect/Detect (bypass in `CheckHit.Protect`).

## Ability/flag table updates

- SliceMoves (Sharpness): + Psycho Cut, Sacred Sword, Air Cutter, Cross Poison
- SoundMoves (Soundproof): + Snarl
- BallBombMoves (Bulletproof): + Bullet Seed
- WindMoves (Wind Rider): + Heat Wave, Air Cutter
- ContactMoves bitfield extended 4 bytes (Fake Out, Flip Turn, Wood Hammer,
  Head Smash, Drill Run, Sacred Sword, Brick Break, Nuzzle, Dual Wingbeat,
  Low Sweep, Cross Poison, Phantom Force make contact)
- AI: UsefulMoves + the obvious attackers; RecklessMoves + EFFECT_SCALE_SHOT

## Animations

All 26 moves have new animations in `data/moves/animations5.asm`
(new floating section "Move Animations 5"), composed from the
polished-ported objects/GFX already in the repo. Highlights: Overheat
(charge-up flames → flamethrower torrent → explosions), Phantom Force
(warp-away vanish on turn 1, shadow strike on turn 2), Brick Break
(screen appears, chop, glass-shatter SFX + shards), Flip Turn
(dash + splash + U-turn-style exit), Leaf Storm (darkened-sky leaf
barrage). Multi-hit anims (Bullet Seed, Scale Shot) are deliberately short.

## Bank/space changes (needed to fit)

- `MoveDescriptions` moved out of the overfull `bankB` into its own floating
  section "Move Descriptions" (all consumers use `BANK(MoveDescriptions)`,
  so this is transparent).
- `BattleCommand_TrapTarget` body moved to the Battle Effect Overflow bank
  (`BattleTrapTarget_Core`) — the Effect Commands bank was full.
- Old unused vanilla `BattleCommand_FakeOut` body removed (label now falls
  through to FlinchTarget; the `fakeout` command byte is unused by scripts).

## Bug fix found along the way

`CheckHit.FlyDigMoves` had the Fly/Dig move lists **inverted** relative to
vanilla (a mon using Fly could be hit by Earthquake but not Gust, and vice
versa for Dig). Fixed: FLYING now checks the Gust/Twister/Thunder/etc. list.

## Testing notes

- ROM builds with rgbds 0.5.2 and boots (verified in emulator to title).
- Not yet play-tested in battle: recommend the usual checklist pass —
  especially Fake Out (first-turn window + priority), Phantom Force
  (semi-invulnerability, Protect bypass, miss branch of the animation),
  Scale Shot (hit counts with/without Skill Link, stat changes on KO),
  Brick Break vs screens and vs a Ghost-type, Sacred Sword vs an
  Iron Defense user.
- To test quickly, give a few of these moves out via a learnset edit or
  your usual cheat workflow (nothing learns them yet).

# Batch 2 — same day, moves 378-413

36 more moves added (IDs 378-413, in this order): HEADLONGRUSH, SHADOW_BONE,
DIRE_CLAW, BARB_BARRAGE, INFERNAL_PARADE, KOWTOW_CLEAVE, ARMOR_CANNON,
SHELLSIDEARM, GLAIVE_RUSH, DRAGON_DARTS, APPLE_ACID, GRAV_APPLE, PSYSHIELD,
RAGING_FURY, STRANGESTEAM, EERIE_SPELL, BANEFUL_BUNKER, RAGING_BULL,
FICKLE_BEAM, STONE_AXE, QUIVER_DANCE, STEALTH_ROCK, DEFOG, BODY_PRESS,
WORK_UP, SUPERPOWER, FIERY_DANCE, FOUL_PLAY, RAGE_FIST, CRUSH_CLAW,
FORCE_PALM, HAMMER_ARM, CIRCLE_THROW, FREEZE_DRY, BOUNCE, DRAGON_TAIL.

Per the design direction: all single-target mechanics match the modern games;
spread/ally aspects are dropped (no double battles). Nothing learns these yet.

## New frameworks

- **Stealth Rock** — full hazard framework: bit 7 of the screens byte,
  `BattleCommand_StealthRock` (fails if already set), switch-in damage of
  1/8 max HP scaled by ROCK effectiveness (1/32 up to 1/2), hooked into the
  same switch-in path as Spikes/Toxic Spikes. Rapid Spin / Mortal Spin
  clear it; **Stone Axe** (`EFFECT_STEALTH_ROCK_HIT`) sets it after damage,
  including when the hit KOs.
- **Defog** — lowers the target's evasion, then clears Spikes, Toxic
  Spikes and Stealth Rock from BOTH sides plus Reflect/Light Screen on the
  target's side. A Protect block stops it; a failed evasion drop doesn't.
- **Glaive Rush** — after it lands, the user can't be missed and takes
  double damage until the start of its next turn (new wram flags, hooks in
  CheckHit and DamageCalc; confusion self-hits excluded).
- **Baneful Bunker** — protects (+4 priority, shares the Protect counter),
  and poisons attackers whose blocked move made contact (respects
  Poison/Steel typing, Immunity/Pastel Veil, the attacker's own Safeguard).
  A plain Protect clears the bunker flag.
- **Body Press** — damage is computed from the user's DEFENSE (stat stages
  included) instead of Attack, on both crit and normal paths.
- **Foul Play** — damage uses the TARGET's Attack stat and stat stages.
- **Freeze-Dry** — FreezeHit (10% freeze) plus a type-chart override: WATER
  rows read as super-effective, in both the damage loop and the
  wTypeMatchup path (so the message and AI agree with the damage).
- **Shell Side Arm** — before damage, compares Atk×(target SpD) vs
  SpA×(target Def) (stats halved together until they fit 8 bits) and
  rewrites the move's category to whichever hits harder; 20% poison.
- **Dire Claw** — 50% chance of poison, paralysis or sleep (equal thirds;
  sleep applied silently through the usual immunity/Safeguard/ability
  checks, 1-3 turns).
- **Rage Fist** — every hit the mon takes is tallied (new wram counters,
  hooked into ApplyDamage; hits on a Substitute don't count; counter
  resets when the mon is sent out). Power = 50 + 50/hit, capped at 250
  (the engine's power byte can't hold 350).
- **Eerie Spell** — damages and saps 3 PP from the target's last used
  move (adapted from Spite, silent when it can't).
- **Fickle Beam** — 30% chance to double the damage with a "going all
  out!" message before the animation.
- **Bounce** — proper two-turn charge ("sprang up!"), flying
  semi-invulnerability (Gust/Thunder etc. can still hit), 30% paralysis.
- **Circle Throw / Dragon Tail** — damage, then the standard force-switch
  (dragged-out trainer mon / ends wild battles), at the bottom of the
  priority table like Roar/Whirlwind.
- **Superpower / Hammer Arm / Headlong Rush** — self stat drops after the
  hit (Atk/Def, Speed, Def/SpD via Close Combat's effect respectively),
  all added to the self-inflicted-drop exemption (bypasses Mist etc.).
- **Quiver Dance / Work Up** — multi-stat boosts using the deferred
  stat-message system (SpA/SpD/Spe and Atk/SpA).
- **Infernal Parade** — Hex's double-vs-status effect now runs through a
  script with a burn chance (Hex itself has 0% so it is unchanged;
  Infernal Parade burns 30%).
- **Raging Bull / Armor Cannon / Psyshield Bash / Fiery Dance / Apple
  Acid / Grav Apple / Barb Barrage / Shadow Bone / Crush Claw / Force
  Palm / Strange Steam / Kowtow Cleave / Dragon Darts / Raging Fury** —
  built on existing effects (screen-shatter, Close Combat, DefenseUpHit,
  new SpAtkUpHit, SpDef/Def-down hits, Venoshock-double + poison,
  paralyze-hit, confuse-hit, always-hit, double-hit, rampage).

## Table updates

- Sharpness: + Kowtow Cleave, Stone Axe. Soundproof: + Eerie Spell.
  Iron Fist: + Rage Fist, Hammer Arm. Contact bitfield extended.
- Priorities: Baneful Bunker +4, Circle Throw/Dragon Tail bottom tier.
  Metronome can't call Baneful Bunker.
- AI UsefulMoves: + the obvious attackers.

## Bank housekeeping

The whole damage-stat block (`PlayerAttackDamage`/`EnemyAttackDamage` and
helpers) moved to the Battle Effect Overflow bank behind farcall stubs —
the Effect Commands bank was full. That's also where the Sacred Sword /
Body Press / Foul Play stat swaps live now.

## Testing priorities for this batch

Stealth Rock end-to-end (set, switch-in damage scaling vs Fire/Flying
types, Rapid Spin/Defog clearing, Stone Axe), Glaive Rush's two-turn
vulnerability, Baneful Bunker vs contact and non-contact moves, Shell
Side Arm's category choice, Foul Play vs a Swords Dance user, Body Press
with Iron Defense, Rage Fist ramping, Bounce's charge turn, and Dragon
Tail in wild vs trainer battles.

# Animation pass — 2026-07-30 (mae-pokeorange ports + fixes)

Where mae-pokeorange (Ancient Platinum engine) has a real animation for one
of the new moves, it was ported into `animations5.asm` (17 moves; the rest
of its "new move" labels are `anim_ret` stubs). Supporting data ported into
`objects.asm` / `framesets.asm` / `oam.asm` / `object_gfx.asm`:
31 new `ANIM_OBJ_*`, 18 framesets, 14 OAM sets, 2 GFX sheets
(`rockpolish.png`, `bigglowspiked.png`) and 2 custom palettes
(CHARRED, HEAT_WAVE). Everything that already existed under a polished
(`PC_*`) or vanilla numbered name was content-matched and reused rather
than duplicated.

**From pokeorange:** Overheat, Fake Out (the Encore-style clapping hands),
Iron Defense, Rock Polish, Heat Wave, Bullet Seed (shortened per hit),
Rock Tomb, Mud Shot, Air Cutter, Magical Leaf, Signal Beam, Superpower,
Crush Claw, Force Palm, Hammer Arm, Bounce. Brick Break is a hybrid:
pokeorange's hovering hand + chop, keeping the screen-shatter.

**Fixes in the same pass:**
- Fickle Beam: beam now uses the full Hyper Beam 4-segment chain + beam
  head, so it reaches the target instead of stopping halfway.
- Scale Shot: fires three scales per hit.
- Phantom Force turn 1: slow Faint Attack-style fade
  (ANIM_BG_FADE_MON_TO_WHITE_WAIT_FADE_BACK), then the pic is hidden
  before the fade is released, so the user stays gone until the turn-2
  strike.
- **Superpower "sometimes no stat drop" bug:** when a hit broke a
  Substitute, `DoSubstituteDamage` zeroed the move's effect byte, so the
  self stat drop ran through the *opponent-drop* path (25% AI-miss roll,
  Mist/ability checks, wrong side). Now self-stat-change moves
  (Superpower, Hammer Arm, Close Combat/Headlong Rush, Scale Shot, Draco
  Meteor/Overheat/Leaf Storm, Shell Smash) keep their effect byte on sub
  break. Also: Defiant/Competitive no longer proc off these moves' own
  self-inflicted drops.
