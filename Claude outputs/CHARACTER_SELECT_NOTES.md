# Trainer-sprite character select (Polished Crystal style)

Replaces the "Gold / Indigo / Lyra / Mint" text menu at the start of a new game
with all four trainer pics on screen at once and a ▼ cursor.

## Files changed

- `engine/menus/init_gender.asm` — `InitGender` rewritten as the sprite screen,
  plus the `CharSelect_*` helpers and tables.
- `engine/menus/intro_menu.asm` — `AreYouABoyOrAreYouAGirl` now loops around a new
  `ConfirmPlayerChoice` (full-size pic + "So, this is you?" yes/no, like Polished).
- `data/text/common_2.asm` — added `Text_SoThisIsYou`.
- `gfx/player/mint.png` — shifted 3px right (see "Mint" below). `mint.2bpp` is
  regenerated by `make`.

## How it works

Left/right moves the ▼, A confirms. Order is Gold, Indigo, Lyra, Mint — the same
order the old text menu used, so `wPlayerGender` values are unchanged (0, 2, 1, 3).

Each 7x7 pic is drawn as its middle **5 columns** (5x7 tiles). Four of those is
140 tiles and only 128 BG tiles are addressable, so pics 1-3 go into VRAM bank 0
at tiles `$01`, `$24`, `$47` and the fourth goes into **VRAM bank 1** at `$01`,
reached through bit 3 of the attribute map — exactly what Polished does. The tile
copy runs with the LCD off, because the vblank tile-request handler always writes
to bank 0.

Everyone keeps their own colors: BG palettes 1-4 hold Gold's, Indigo's, Lyra's and
Mint's real palettes, and the three you are *not* on get every channel blended
halfway to white (`c / 2 + 16`, one masked shift and one or). Color 0 of each is
set to the screen's light blue instead of white, so the pics sit flush on the
background instead of each showing a white box.

## Things to know

- **Bank space.** All the new code lives in the `Crystal Features 1` bank next to
  the rest of `init_gender.asm`, because `InitGender` calls `InitGenderScreen` and
  friends with plain `call`s. It adds roughly 700 bytes. If rgblink complains that
  the section doesn't fit, move one of the other `INCLUDE`s out of that section in
  `main.asm` (`engine/events/move_tutor.asm` or `engine/events/celebi.asm` are the
  easy ones to relocate) rather than splitting this file.
- **Lyra's colors.** She uses `PlayerPalette` (Gold's red), which is what
  `GetPlayerOrMonPalettePointer` gives her everywhere else in the game, so the
  select screen matches the pic you see one screen later. If you'd rather she were
  blue on this screen, change the third entry of `CharSelectPalettes` in
  `init_gender.asm` to `LyraPalette` — but then she'll change color when Oak shows
  her, so it's probably worth changing `GetPlayerOrMonPalettePointer` too.
- **Mint.** Her art sat 4px left of center in the 56x56 frame and her poké ball
  spilled into the leftmost tile column, which the 5-column crop would have clipped.
  `mint.png` is shifted 3px right, which both fixes that and centers her better in
  the full-size pic. Nothing else uses that file (her backpic and card pic are
  separate).
- **Reverting.** All four files are tracked, so `git checkout --` on them undoes
  everything.
