Jirachi uses the supplied single-frame front and back artwork. The normal
palette is shared with the menu/overworld icon; the back's original yellow
and blue shades are mapped to the front palette without changing its pixels.
The shiny palette keeps the normal yellow (RGB 31, 27, 9) and changes the
blue tags to the exact 15-bit red from Emerald's shiny palette slot 5
(RGB 28, 9, 6; expanded RGB 230, 74, 49). Emerald uses two ribbon shades;
slot 5 is the dominant one, retained here for the four-color artwork.
Source: https://github.com/pret/pokeemerald/blob/master/graphics/pokemon/jirachi/shiny.pal
Both battle animation scripts hold frame 0 because no additional artwork
frames were supplied. Frames and bitmasks are generated by the normal build.

The species is appended as internal ID 496 and the final regional Pokédex
entry. Existing species IDs and the size of the saved Pokédex bitfields are
unchanged (495 and 496 species both use 62 bytes per bitfield).

The learnset combines every implemented historical move in the project's
pinned Smogon reference with Luminescent Platinum's level schedule and
Zap Cannon tutor compatibility. Rest, absent from Lumi's level-up list,
retains its canonical level 63. Ordinary machine and utility-tutor routes
are used where available; remaining moves use the existing Blackthorn
tutor. Jirachi is genderless, cannot breed, and has no egg moves.

Sources and exact acquisition routes: `tools/testdata/jirachi.json`.
The cry is a synthesized Gen II voice, following the expanded roster's
existing cry system. The footprint comes from pret/pokeemerald.
