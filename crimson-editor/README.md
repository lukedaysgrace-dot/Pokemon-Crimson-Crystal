# Crimson Editor

A local save editor for Pokémon Crimson Crystal, implemented independently from
the architecture described in [the implementation plan](../CRIMSON_EDITOR_IMPLEMENTATION_PLAN.md).
Polished Editor by KohKaiSern / Rev3lation inspired that plan; no upstream editor
code or assets were copied. The editor's original code is MIT licensed. Game
assets and Pokémon IP retain their original rights.

The editor lives in this repository under `crimson-editor/`. It reads the parent
ROM source by default; no vendored copy or submodule is required. `vendor/` is
ignored if you prefer a separate checkout. All save processing runs locally in
the browser, with no analytics or save uploads.

## Run

Use Node 22+ and pnpm 11.25.0:

```sh
cd crimson-editor
pnpm install --frozen-lockfile --store-dir .pnpm-store --node-linker=hoisted --config.enable-global-virtual-store=false
pnpm dev
```

Open the local URL printed by Vite. The current format-4 profile includes
Phantump, Trevenant, Horn Leech, and their normal/shiny sprites.
Phantump evolves at level 32. Previous
format-3, format-2, and September 9 build profiles and
local normal/shiny sprites are included, so running the editor does not require
building the ROM. Select a save through **Open a save file**. Download writes a
new file; it never overwrites the original on disk. Validation errors block export.

The move filters include the full Blackthorn tutor lists and each species'
family breeding moves, including Phantump's inherited moves for Trevenant.

The public documentation website includes a **Save Editor** navigation tab.
Build its editor with `pnpm build:website`, then run `pnpm test:website`.
Commit and push the resulting `docs/editor/` files and `docs/.nojekyll` with the
source changes to update the existing GitHub Pages site. See
[hosting instructions](docs/updating.md) for details.

## Verify

```sh
pnpm check
pnpm test
pnpm exec playwright install chromium
pnpm test:ui
pnpm build
# Requires matching .gbc + .sym, generated by the ROM build:
pnpm validate-data
pnpm audit:sprites
pnpm check:sprites
pnpm exec tsx tools/fixtures/export.ts
python tools/roundtrip/pyboy_check.py
```

The Python emulator check requires PyBoy (the repo's Linux `.venv` can be used).
Use `--crimson PATH` when the ROM is outside the parent directory. It uses the
existing PC harness and an in-memory MBC5 surrogate, preserving the ROM on disk.

Sprite extraction preserves every physical picture-table row, including the
dummy species and Unown placeholders, and verifies front/back pointers against
the compiled ROM. `audit:sprites` checks every normal/shiny pixel against the
matching source art and ROM palettes. For another profile, pass
`--crimson PATH --profile static/gamedata/BUILD.json`. After regeneration,
`pnpm exec tsx tools/prune-sprites.ts --write` removes only generated PNGs no
longer referenced by any included profile. The unit tests reject stale assets.

[save format](docs/save-format.md) and [manual testing](docs/manual-test.md).
