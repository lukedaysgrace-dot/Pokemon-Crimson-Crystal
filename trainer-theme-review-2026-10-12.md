# Trainer Theme Review — 2026-10-12

Scope: every party in `data/trainers/parties.asm` (584 parties). Types were read from this
game's `base_stats` data, so custom typings (Noctowl Psychic/Flying, Ledyba Bug/Fighting,
Ursaring Ground/Normal, Ampharos Electric/Dragon, etc.) count.

Classes that came back **100% on-theme**: Bird Keeper, Bug Catcher, Fisher, Swimmer M/F,
Firebreather, Blackbelt, Battle Girl, Hex Maniac, Ninja, Aroma Lady, Skier, all gym-leader
puzzle trainers except Goldenrod's, and every Johto/Kanto leader + Elite Four except the notes below.

file assembles cleanly).

Croconaw 32 -> Feraligatr, Pupitar 46 -> Tyranitar, Eusine's Haunter -> Gengar). No trainer
Pokémon is now above its level-evolution level, except the intentional skips: all Pikachu,
